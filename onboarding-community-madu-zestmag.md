# Onboarding Plan: Community Manager

Brand: Madu Zestmag · orang baru: Rifki · mulai: 1 september.

Filosofi: onboarding = proses 4 minggu (bukan orientasi 1 hari); tiap role berbeda; ada buddy; checkpoint terukur.

## Roadmap 4 Minggu

### Week 1: Foundation — Orientasi
- **Aktivitas:** Kenalan tim, pahami brand (positioning/tone/audiens), pelajari tools, baca SOP & checklist, observasi meeting, kenalan buddy
- **Checkpoint:** Bisa jawab: brand tentang apa, role tugasnya apa, alur kerja, tools, eskalasi ke siapa

### Week 2: Guided Practice — Praktik dengan pendampingan
- **Aktivitas:** Mulai task dengan buddy, ikuti workflow (supervisi), buat output pertama (review 100%), terima feedback detail
- **Checkpoint:** Output pertama dinilai vs quality checklist

### Week 3: Supervised Execution — Lebih mandiri
- **Aktivitas:** Kerja lebih mandiri (spot-check), handle revisi sendiri, kontribusi brainstorming
- **Checkpoint:** Output konsisten? Follow workflow tanpa reminder? Tahu kapan eskalasi?

### Week 4: Independence Assessment — Penilaian kemandirian
- **Aktivitas:** Supervisi minimal (sample-based), deliver output mandiri
- **Checkpoint:** Lihat kriteria lulus di bawah

## Penyesuaian untuk Role Ini

**Community Manager:** FAQ list, response guideline, roleplay handling complaint, escalation protocol

## Materi Week 1 (Foundation)

- [ ] Welcome document
- [ ] Brand brief
- [ ] Role description
- [ ] SOP relevan
- [ ] Quality checklist
- [ ] Workflow overview
- [ ] Panduan tools
- [ ] Editorial calendar berjalan
- [ ] Contoh output terbaik & terlemah
- [ ] FAQ + common mistakes
- [ ] Contact & escalation guide

## Buddy System

- Buddy: anggota tim berpengalaman ≥3 bulan, peran setara
- Check-in: 15 menit/hari (Week 1–2), 2×/minggu (Week 3–4)
- Tugas buddy: point of contact operasional, bantu navigasi tools/proses, feedback informal
- Bukan tugas buddy: tanggung jawab kinerja (itu Lead), gantikan training formal

## Kriteria Lulus (Akhir Week 4)

| Kriteria | Standar | Lulus? |
| --- | --- | --- |
| Output quality | Konsisten ≥80% checklist |  |
| Workflow compliance | Bisa follow mandiri |  |
| Timeliness | ≥90% on-time |  |
| Escalation awareness | Tahu kapan & ke siapa |  |
| Communication | Tidak ada red flag dari tim |  |
| Brand understanding | Output on-brand & on-tone |  |

_Semua lulus = READY. 1–2 belum = extended 1–2 minggu. Mayoritas belum = evaluasi mendalam._
